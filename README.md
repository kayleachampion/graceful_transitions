# Graceful Transitions
This is a course module on decomissioning, handoffs, and transitions in software engineering. My original purpose for this module is to use it as part of teaching CSS 360 Software Engineering at the University of Washington Bothell. 

That said, I'm doing this project as part of my collaboration with the RESA (the Research Software Alliance, https://www.researchsoft.org/) and CURIOSS (the Community for University and Research Institution OSPOs) Task Force on Succession Planning for code; I invite interest and participation from anyone with an interest in graceful transitions in software and peer production projects more generally!
